Project 2: The "Context-Aware" Technical Manual Assistant

Focus: Transformer Architecture, Open Source Models, NLP Pre-processing (Phases 3 & 4)

Scenario: A legacy engineering firm has massive technical manuals (PDF/Text) that are too large to paste into a standard context window. They want an on-premise solution (using open-source models) to answer questions about specific machinery without uploading data to the cloud.

Objective: Create a simplified RAG (Retrieval-Augmented Generation) workflow using Python and Hugging Face.

Key Concepts Applied:
NLP/Tokenization: Cleaning text and splitting it into chunks (simulating how Transformers handle sequences).
Hugging Face: Loading an open-source model (e.g., distilbert for Q&A or a quantized Llama model).
Attention Mechanism: Manually implementing a "search" to find relevant text chunks before asking the AI.

Instructions:
Data Prep: Take a long text file (e.g., a 5-page public domain technical manual or article).
Preprocessing: Use Python (NLTK or Spacy) to clean the text and split it into chunks of 200 words.
Retrieval (The "Attention" Simulation): Write a script that takes a user question (e.g., "How do I reset the pressure valve?") and scans your text chunks for matching keywords. Select the top 2 most relevant chunks.
Generation: Pass the User Question + Selected Chunks into a Hugging Face pipeline (Question-Answering or Text-Generation model).
Refinement: Ensure the model answers only based on the provided text chunks.

Deliverable: A Jupyter Notebook showing the code for text chunking, the keyword search logic, and the final answer generated by the open-source model.
